# Отчет о работе с AI Coding Agents

## 1. Cursor (Hobby, CLI)
- **Задачи:** Анализ кода, восстановление требований, модернизация (SQLite, исправление ошибок), реализация виртуального портфеля.
- **Промпты:** Использовался один большой сквозной промпт для автономного выполнения.
- **Ошибки и корректировки:** Агент успешно справился с задачей. Из-за ограничений окружения (Python 3.15) потребовалось вручную прервать установку некоторых пакетов, но это не повлияло на генерацию кода.
- **Проверка:** Проверен файл ANALYSIS.md (14 пунктов требований), проверены диффы файлов. Проект запускается через `python manage.py runserver`.
- **Время и итерации:** ~7 минут, 1 запрос.

## 2. Windsurf (Free, Cascade)
- **Задачи:** Анализ кода, модернизация (SQLite, отключение Celery), реализация мониторинга акций (Watchlist).
- **Промпты:** Один большой промпт и маленький для исправлений.
- **Ошибки и корректировки:** Агент столкнулся с зависанием `pip install` (компиляция pydantic-core) ооочень долго не мог установить эти зависимости  , что пришлось писать второй раз и просить доделать работу без них , но самостоятельно адаптировал код под отсутствие библиотек Tinkoff API (добавил `try/except`), что позволило проекту работать без них.
- **Проверка:** Сгенерирован подробный ANALYSIS.md (14 требований, 14 дефектов). Приложение успешно запущено локально, проверена работа новой функции (миграции прошли без ошибок).
- **Время и итерации:** ~12 минут, 2 запроса (с учетом времени на обдумывание).
